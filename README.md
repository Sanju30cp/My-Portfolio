# Sai Saroja Bethu - Personal Portfolio Website

A premium, interactive, and responsive portfolio website showcasing academic achievements, computer science skills (with specialization in AI/ML & Data Analysis), projects, certifications, and internship experiences.

**🚀 Live Demo:** [https://sanju30cp.github.io/My-Portfolio/](https://sanju30cp.github.io/My-Portfolio/)

---

## 🛠️ Tech Stack & Libraries

- **Frontend Core:** HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Styling & Icons:** Poppins Google Font, Font Awesome 6.4.0
- **Libraries:** Particles.js (interactive canvas background particles)

---

## ✨ Key Features

- **Dynamic Theme Toggle:** Smooth transitions between Light and Dark mode (Dark theme set as default).
- **Interactive Animations:**
  - Typing effects in the hero header.
  - Floating card animations for workspaces/tech graphics.
  - Particle background network effects reacting to mouse hover/click.
  - Skill progress bars that animate dynamically on load.
  - Statistics numbers that count up incrementally.
- **Unified Navigation:** Full desktop/mobile responsive navbar with active state tracking.
- **Section Layouts:**
  - **About Me:** Brief professional summary and goals.
  - **Education:** Structured grade timeline showing CGPA/B.Tech grades.
  - **Technical & Soft Skills:** Rated bars for Python, Java, Django, Excel, and Power BI, plus interactive interest badges.
  - **Featured Projects:** Cards with repository source codes and deployed live demo links.
  - **Certifications:** Verified professional certificates (Google, Cisco, Oracle, Salesforce, IBM).
  - **Internships:** Consolidated work experiences (Tata Group, VaultofCodes, Agnivra).
  - **Contact Form:** Interactive form to send messages directly.

## 🏃 Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sanju30cp/My-Portfolio.git
   cd My-Portfolio
   ```
2. **Open index.html:**
   - Double-click the `index.html` file to run it in any modern browser, or
   - Use a local development server like VS Code's **Live Server** extension.
